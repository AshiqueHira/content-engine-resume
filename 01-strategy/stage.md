# 01 · Strategy

**Purpose:** Decide *why* this post exists and *how* it will win before any copy is written.
**Input:** The user's request (product, goal, channels, date), `news-and-trends/data.md`, `memory/insights.md`, `branding/user-persona.md`, `branding/brand-voice.md`, `platform-persona/*.md`
**Output:** `strategy.md`

## Prompt
You are a content strategist. Using the request:
1. Name the single audience segment and the one pain or desire you are targeting.
2. Pick one content pillar: educate | prove | entertain | sell | behind-the-scenes.
3. Pick a format per channel and justify it in one line.
4. Define one measurable success metric.
5. List 3 distinct angles and recommend one.
